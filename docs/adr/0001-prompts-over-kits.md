# ADR-0001: Standalone session prompt library

- Status: superseded by [ADR-0002](0002-devl-spiral.md)
- Date: 2026-06-09

## Context

The original repository coordinated project sessions through copied prompts and separate continuity documents.

## Decision

Superseded. Consumer project context now belongs exclusively to native Spec Kit artifacts. ai-promptkit retains only maturity-oriented pre-spec agents, one brownfield takeover prompt and integration maintenance.

## Consequences

- No project session wrappers or parallel context documents are scaffolded.
- Existing consumer documentation is preserved but is not created or governed by ai-promptkit.
