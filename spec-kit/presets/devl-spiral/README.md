# DEV|L Spiral preset

Append-only customization that carries one DEV|L maturity turn inside native Spec Kit artifacts. It adds no commands, feature types or external context files.

```text
specify preset add --dev extern/ai-promptkit/spec-kit/presets/devl-spiral --priority 10
specify preset resolve constitution-template
specify preset resolve spec-template
specify preset resolve plan-template
```

Install before the first constitution. For an existing constitution, review the appended principles and deliberately rerun the native constitution command. Reinstall after an accepted submodule upgrade.
