# Prompt registry

ai-promptkit intentionally provides no feature-delivery or session-continuity prompts. Those would compete with native Spec Kit artifacts.

| Prompt | Purpose | Mutation |
|--------|---------|----------|
| [takeover.md](takeover.md) | One-time incorporation of Spec Kit into an existing codebase | Spec Kit files and installed preset only |
| [doctor.md](doctor.md) | Read-only integration diagnosis | none |
| [upgrade.md](upgrade.md) | Deliberate pinned extension/preset upgrade | submodule pointer and installed preset |

Feature work uses the installed native Spec Kit commands. Maturity framing uses Engineer, Scientist or Business before `speckit.specify`; [Projectant](../agents/projectant.md) leads the upstream project-initiation stage.
